## 🎮 游戏简介

《频率 1987》是一款 2D 横版双时空叙事游戏。跟妈妈吵架的女儿，深夜在即将拆迁的老房子里，用外婆留下的老收音机调到一个不存在的频率——电话那头，是 1987 年一个正在为梦想挣扎的陌生女孩。

- **前两章**：横版探索 + 对话 + 解密，玩家在 2007 年与 1987 年之间切换时空，验证因果
- **第三章**：双屏平台跳跃——声波可视化成跳跃路径，两个人互为对方造路，BGM 攀升中合屏相遇
- **画风**：温暖手绘水彩立绘，三层视差卷轴，80 年暖黄胶片调 / 00 年冷青调
- **平台**：PC 完整版（DS5 手柄双摇杆 + 键盘双区操控）+ 小红书小程序互动叙事版
