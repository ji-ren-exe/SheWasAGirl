## 〇、一句话看懂这个项目

**《妈妈的存档》**：一间老房子，两个时空。你以 80 年代的妈妈和 00 年代的女儿双视角，玩一场"双向靠近"的游戏——妈妈在过去的每一次选择都会在女儿的世界留下物理痕迹；前两章的选择决定第三章母女能否"同时相遇"。最终章分屏双控，妈妈与女儿在同一时刻、不同时空并肩通关，**胜利 = 相遇**。

## 一、你的 idea 评估（坦率版）

### 1.1 真正的亮点（这三个点要保留并放大）

| 亮点 | 说明 |
|---|---|
| **"妈妈是女儿人生最忠实的玩家"** | 这句是全场最佳。它同时命中两个赛道：萨福（关系的本质是靠近）和 Tripo（为她而设计、创造新规则——把"玩家"这个身份安在妈妈身上，本身就是反常规的规则隐喻）。这句要成为游戏的 Slogan 级概念，贯穿所有材料。 |
| **空间即叙事** | 一间老房子承载双时空，成本极低但叙事密度极高。三章共用一套场景资产，开发量可控，非常适合 3.5 天极限开发。 |
| **三章对标三个神级关卡** | 有明确的体验标杆，评委能瞬间 get 到你的野心，演示时有话题点。 |

### 1.2 需要立刻修正的三个问题

**问题 1：双赛道是"分配"而非"缝合"**
现在"妈妈贴萨福、女儿贴 Tripo"是简单的一人一个命题。评委看的是**一个机制如何同时回答两个命题**。
→ 解法：统摄性核心机制 **"双向靠近"**。萨福说"关系是一次次靠近"，你的核心循环就是"靠近"（女儿通过时空切换靠近妈妈的过去）；Tripo 说"创造新规则"，你的新规则就是 **"胜利 = 相遇"**（没有敌人、没有失败，通关标准是两个人走到彼此面前）。一个机制，两个命题都答了。

**问题 2：因果必须是"物理化、可触摸"的**
《耻辱2》A Crack in the Slab 的震撼在于：你在过去挪一个花瓶，现在就能拿到钥匙——**玩家亲手验证因果**，而不是听系统说"你改变了未来"。
→ 解法：第一章的每个影响都做成**房间里的实体变化**（墙缝里的信、日历上的圈、存钱罐里的硬币），女儿必须亲手发现。

**问题 3：第三章的"技能"不能是复杂技能树**
3.5 天做不出技能树。前两章的选择要影响第三章的**"靠近方式"**，而不是战斗能力。
→ 解法：技能即"双向解锁"——每项能力都是妈妈帮女儿 / 女儿帮妈妈的通道（详见第三章设计）。

## 二、三个神级关卡拆解 → 化用方案

### 2.1 第一章《墙缝》——对标《耻辱2》"A Crack in the Slab"

**原作神在哪**：时间装置让玩家在"豪宅全盛期"与"破败期"间穿梭；过去挪一个花瓶，现在的钥匙就到手。**因果是物理的、可验证的、有延迟反馈的**——玩家玩的是"时间物理学"。

**化用到 She Game**：
- 同一房间双版本：**80 年代（暖黄、鲜活、妈妈年轻）** vs **00 年代（冷青、凌乱、女儿长大）**。
- 玩家以女儿（00 年）为主视角，通过"妈妈的旧物"触发**回响**（切到 80 年）。
- 核心循环：**在 80 年做一件小事 → 00 年房间出现物理变化 → 女儿亲手发现**。
  - 80 年妈妈把一封信塞进墙缝 → 00 年女儿在墙缝里摸出信（写给"未来的你"）
  - 80 年妈妈修好缝纫机 → 00 年女儿用缝纫机补好一件衣服（对应后续情节）
  - 80 年妈妈擦干净钢琴 → 00 年钢琴能弹响 / 不擦则蒙尘（选择分支）
  - 80 年妈妈在日历上画圈"囡囡生日" → 00 年那页日历仍挂在墙上
  - 80 年妈妈往存钱罐投硬币（旁边写着"囡囡的大学"）→ 00 年存钱罐沉甸甸
- **首章泪点**：女儿发现妈妈 80 年代的所有"小事"几乎都关于一个**尚未出生的人**。结尾抛出钩子：00 年的房间里出现一件"80 年代不该存在的东西"——指向妈妈当年做过一个重大选择（放弃南下 / 卖掉嫁妆 / 拒绝离开）。

### 2.2 第二章《回响》——对标《羊蹄山之魂》序章"一键切换"

**原作神在哪**：惊艳感来自**同场景不同身份/时空的瞬间叠化**——世界在指尖翻转，切换本身就是表演。

**化用到 She Game**：
- 玩法升级为**一键切换**：按键 → 房间在 80/00 时空"叠化翻转"（模糊→清晰）。切换瞬间两个时空的"人影"错位叠影（80 年妈妈在切菜，00 年女儿坐在同一位置发呆）。
- **小解密链：妈妈藏起的生日礼物**。线索是**半透明的**——只有切换时空才能看到另一半：
  - 80 年抽屉里有半张照片 → 00 年抽屉有另外半张 → 拼合：妈妈年轻时的合影 + 一枚戒指
  - 80 年收音机播放的频道 → 00 年同一频率响起（妈妈的歌）
- **情绪峰值设计**：连续快速切换时，两个时空的"家人影"逐渐重合——第一次"看见彼此"（预告第三章）。
- **第二章泪点**：生日礼物其实是**妈妈舍不得留给自己的东西**——舞蹈鞋 / 录取通知书，附一张字条"你要替妈妈去跳舞"。女儿第一次明白：**妈妈的梦想不是放弃，是转移到了我身上**。
- 结尾：切换功能"失灵"，两个时空开始**同时显现**——第三章机制预告。

### 2.3 第三章《双声》——对标《双影奇境》终章分屏合璧

**原作神在哪**：分屏双角色、各自时空各自任务，**最终画面合屏相遇**——机制即叙事的高潮。

**化用到 She Game**：
- **分屏**：左 = 80 年代妈妈，右 = 00 年代女儿，同一时间线各自推进。
- **各自的任务**：妈妈需要"放手"（推开老房子的门送女儿远行）；女儿需要"回头"（推开同一扇门回家）。**两边的门是同一扇门**——80 年这侧是送别，00 年那侧是归途。
- **同步谜题（双时空联动升级）**：妈妈时空移动某件家具 → 女儿时空出现新落脚点；女儿点亮灯 → 妈妈那边天亮。
- **输入方案落地**：
  - **DS5 手柄**：左摇杆 = 妈妈，右摇杆 = 女儿（双手各控一人）；L2/R2 = 同步"推门"；触摸板 = 特殊交互"牵手"（BGM 最高潮处触发合屏）
  - **键盘**：WASD = 妈妈，方向键 = 女儿；Shift/空格 = 同步动作
  - **小红书小程序（手机）**：屏幕左右两侧各一块触控区（虚拟摇杆/滑动），选择互动用点按
- **终章高潮**：BGM 攀升，两侧"门"同时推开 → **画面合屏**。女儿在 00 年推开门，看见老房子 80 年代的门廊，妈妈站在那里——等了二十年的一幕。
- **终章泪点**：妈妈只说一句"回来啦"，然后两人一起做一件小事（一起煮一碗面 / 在门槛上并排坐下）。游戏结束在安静的日常里，**不煽情，只留白**。

## 三、完整玩法框架

### 3.1 核心机制：双向靠近

```
      80 年代（妈妈）←———— 回响（时空切换）————→ 00 年代（女儿）
      选择（小事/物理因果）───→ 房间变化 ───→ 女儿亲手发现
      女儿的理解/记忆（第二章）───→ 反向影响妈妈时空（第三章联动）
                     ↓
            最终：两人同时"靠近"到门廊 = 胜利
```

### 3.2 前两章选择 → 第三章"靠近方式"（技能即双向解锁）

| 前两章的选择 | 第三章获得的"能力" | 设计意图 |
|---|---|---|
| 第一章：妈妈留下（未南下） | 妈妈"推门"更有力（可推开更重的门） | 妈妈的爱是女儿的力量来源 |
| 第一章：妈妈卖掉嫁妆 | 妈妈获得"信物"（打开女儿时空的锁） | 牺牲变成钥匙 |
| 第二章：收集记忆碎片 ≥ N | 女儿"回忆"照亮妈妈时空的黑暗 | 理解让妈妈的世界亮起来 |
| 第二章：拼图完整 | 女儿"看见"妈妈的过去（半透明层） | 看见即靠近 |
| 第一章：钢琴擦了 vs 没擦 | 合屏后二人"合奏"（额外结局镜头） | 小彩蛋，鼓励探索 |

**设计铁律**：所有能力都是**双向的**——帮助妈妈的，最终也帮助女儿；没有战斗，只有"靠近"。

### 3.3 双端策略（重要）

- **PC 端（本机演示，比赛主力）**：Unity，完整三章 + DS5 手柄 + 键盘双控。
- **小红书小程序端**：**做"互动叙事版"而非完整玩法移植**——触控双区（两侧摇杆）+ 选择互动 + 简化谜题 + 章节播片。理由：3.5 天做不出完整双端，且小红书小程序对 WebView/游戏能力支持有限；小程序版定位为"体验延伸 + 传播入口"，PC 版为"完整 Demo"。

## 五、画风与 BGM

### 5.1 画风（对标《中国式家长》）

- **风格**：2D 手绘平涂 + 轻微噪点纸质感；暖色主调；人物有年代感细节（妈妈 80s：烫发/的确良/二八自行车；女儿 00s：校服/MP3/翻盖手机）。
- **双时空色温语言**（重要，保证"一键切换"的视觉冲击）：
  - 80 年代：暖黄/胶片感（轻微颗粒、偏色、高光晕开）
  - 00 年代：冷青/数码感（对比更强、边缘更利）
  - 切换时用**叠化 + 色温渐变**（0.3s 内完成），两个时空的人物在过渡帧"错位叠影"
- **场景清单**：老房子外立面、客厅（缝纫机/钢琴/电视）、厨房、妈妈的房间、女儿房间（奖状墙/身高刻痕）、门廊（终章相遇点）。
- **贯穿信物**（三章都出现）：存钱罐、缝纫机、舞蹈鞋、录取通知书、日历、墙缝里的信、那扇门。

### 5.2 BGM（温馨、亲情、可落地）

**参考曲目**（听感方向）：
- 《请回答1988》OST《你不要担心》——80 年代温暖底色
- 久石让《菊次郎的夏天》——《Summer》的轻盈温馨
- 电影《你好，李焕英》配乐——母女主题模板
- 《步履不停》《岁月神偷》配乐——留白与克制
- 《中国式家长》游戏 BGM——同类画风参照
- 坂本龙一《Merry Christmas Mr. Lawrence》（仅第三章高潮段的悲悯层次参考）

**三章音乐方向**：
| 章节 | 音色 | 情绪 |
|---|---|---|
| 一 | 磁带/收音机质感、怀旧钢琴、轻微底噪 | 好奇→温暖→鼻酸 |
| 二 | 主旋律（母女主题）首次完整出现，弦乐垫底 | 悬念→恍然→落泪 |
| 三 | 低音铺垫 → 弦乐+钢琴攀升 → 合屏瞬间主题爆发 → 收尾只剩钢琴单音（煮面场景） | 激动→释然→安静 |

## 六、引擎选型与 AI 开发提示词

### 6.1 引擎对比

| 引擎 | 适合度 | 理由 |
|---|---|---|
| **Unity（首选）** | ★★★★★ | 2D 成熟（URP）、C#、**PC 手柄支持好（Input System 支持 DS5）**、UI/中文字体方案成熟、Timeline 过场、可导出 WebGL；团队招聘面最广 |
| Godot 4 | ★★★★ | 免费轻量、2D 极强、GDScript 上手快、导出 Web 好；DS5 需插件；招人面较窄 |
| RPG Maker | ★ | **不推荐**：时空切换、分屏双控等核心机制无法实现，命题(创造新规则)直接被工具锁死 |
| Cocos Creator | ★★★ | 国内小程序生态最好，但 PC 手柄/复杂机制弱于 Unity；**仅当小红书端必须原生时才考虑** |

> 结论：**主开发 Unity（PC 完整 Demo）；小程序端做简化互动叙事版**。若团队有 Cocos 熟手且时间允许，可用 Cocos 做小程序端。
